# TG_MAPA_BOT

Ранний учебный Telegram-бот на Python и aiogram 2.x: поиск координат, расчёт расстояний, погода через OpenWeather и поиск достопримечательностей. Это исторический проект, полный запуск на актуальном окружении не проверен.

## Структура

- `TG.py` — команды бота и диалоги FSM.
- `Parser.py` — геокодирование, погода, загрузка изображений и парсинг страниц.
- `AIGRAM_TOKEN.py` — чтение токена из окружения; секретных значений в нём быть не должно.
- `data/` — сохранённые HTML-страницы ранних экспериментов.

## Конфигурация

Перед запуском `python TG.py` задайте `BOT_TOKEN` и `OPENWEATHER_API_KEY` в окружении процесса. `.env.example` содержит только имена переменных; `.env` автоматически не загружается. Не добавляйте реальные значения в Git, команды публичных инструкций или отчёты CI.

Код использует aiogram 2.x, geopy, requests, fake-useragent, icrawler, beautifulsoup4 и lxml. Зафиксированного и проверенного набора версий пока нет; aiogram 3 несовместим с текущими импортами.

## Известные ограничения

- Загрузка и отправка изображений привязаны к абсолютным путям Windows.
- Часть состояния хранится в глобальных переменных; параллельная работа нескольких пользователей требует исправления.
- Сетевые запросы синхронные, без явных таймаутов; обработка ошибок неполная.
- Парсинг зависит от внешней разметки сайтов; его работоспособность сейчас не подтверждена.
- Тестов, CI и автоматизированного развёртывания нет.

Ранее опубликованные токены Telegram и ключи OpenWeather необходимо отозвать у провайдеров. Перенос конфигурации в окружение не удаляет старые значения из истории Git.
